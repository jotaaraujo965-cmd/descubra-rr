# Descubra RR — Flutter

Protótipo funcional de um aplicativo turístico gamificado para Roraima.

## Como executar

```bash
flutter pub get
flutter run
```

## O que já está implementado

- Tela de abertura animada
- Login/cadastro com alternância animada
- Início com progresso
- Lista de municípios
- Mapa 2D individual por município usando OpenStreetMap
- Pontos descobertos e bloqueados
- Sistema de códigos de desbloqueio
- Animação de desbloqueio
- Página de detalhes da descoberta
- Coleção "Minhas descobertas"
- Perfil com estatísticas
- Categorias
- Persistência local das descobertas com SharedPreferences

## Códigos de demonstração

- `RR2026`
- `BOAVISTA`
- `PACARAIMA`

O projeto foi estruturado como protótipo/MVP. Para produção, substitua os dados locais por uma API/backend e implemente autenticação real.
